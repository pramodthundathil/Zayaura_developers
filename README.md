# Zayaura Developers — Luxury Architecture & Interior Design Studio Website

A premium, modern, visually immersive, and animated website for **Zayaura Developers**, designed to showcase architectural expertise, luxury interior design, turnkey design-build capabilities, and completed project portfolios for esteemed clients including **Joy Abraham**, **Shihab**, and **Denny**.

## 🌟 Key Features

- **Spatial Antigravity Aesthetics**: Glassmorphism (`backdrop-filter: blur`), subtle 3D mouse parallax tilt effects, floating spatial depth, restrained luxury palette (`#1C1C1C`, `#F4F1EC`, `#A4865A`).
- **Dynamic Animations**: GSAP (GreenSock) and ScrollTrigger animated entrances, staggered project cards, smooth scrolling, and animated statistics counters.
- **Client Portfolio Showcase**: Dedicated project highlights and galleries for distinguished clients:
  - **Joy Abraham Residence** (Kochi, Kerala)
  - **Shihab Architectural Villa** (Thrissur, Kerala)
  - **Denny Corporate Plaza** (Calicut, Kerala)
  - **Site Master Developments & Casa Verde Sanctuary**
- **Dual-State Architectural Showcase**: Interactive Before/After image slider demonstrating raw architectural structure to finished luxury space transition.
- **Dark / Light Mode**: Seamless theme toggle with persistent state (`localStorage`).
- **Complete Page Suite**:
  - `index.html` (Homepage with Hero, Stats, Services, Editorial Portfolio, Interactive Dual Slider, Process Timeline, Quick View Modal)
  - `about.html` (Studio Story, Manifesto, Client Stories & Testimonials)
  - `services.html` (Architecture, Interior Design, Design & Build, Renovation)
  - `projects.html` (Full portfolio showcasing client works)
  - `process.html` (Dedicated 5-step process page, 45-day delivery guarantee, 15-year warranty, free 3D design & site visit assessment)
  - `project-detail.html` (Individual project showcase, concept narrative, specs, and gallery)
  - `contact.html` (Interactive consultation form with JS validation, HQ details, direct WhatsApp link, embedded map)
- **Accessibility & Responsive Design**: Designed across 1920px down to 375px mobile viewports with full `@media (prefers-reduced-motion: reduce)` support.
